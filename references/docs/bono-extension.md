# Bono por extensión de jornadda (Percepciones)

El bono por extension de jornada es asignado a empleados vinculados a un usuario con rol 2 (Podologo)
Este bono no es obligatorio, se asigna deliberadamente por un administrador a algun empleado en especifico
No todos los empleados tienen el bono
Este bono se calcula por periodo , ((salario_diario/8)*2)*Dias_trabajados
Tiene el valor de una hora extra por el numero de dias trabajados(las horas extras se pagan dobles)
Tiene valor de horas extras pero no se considera como tal ya que es un acuerdo entre el administrador y el empleado
Solo aplica en nómina operativa
Si el empleado no recibe el bono, no debe mostrarse en el detalle de nomina del empleado
